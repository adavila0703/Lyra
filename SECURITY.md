# Security

Lyra is a local desktop app. Audio, transcripts, and pages stay on the device. The only network request in v1 is the optional first-run Whisper model download.

## Reporting a vulnerability

**Do not open a public GitHub issue for security bugs.**

Report privately through [GitHub Security Advisories](https://github.com/adavila0703/Lyra/security/advisories/new). Enable **Private vulnerability reporting** in the repository settings if that page is not available yet.

Please include:

- A description of the issue
- Steps to reproduce
- Affected versions / platforms if you know them

We will acknowledge the report and work on a fix before any public disclosure.
